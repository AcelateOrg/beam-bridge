# Как внести вклад

Спасибо, что хотите помочь BEAM. PR и issues приветствуются.

## Перед началом

- Перед крупными изменениями откройте issue и опишите подход: так не придётся
  переделывать готовую работу.
- Отправляя PR, вы соглашаетесь с [CLA](CLA.md). Код под copyleft-лицензиями
  (GPL и т.п.) принять не можем.
- Об уязвимостях пишите не в issues, а как описано в [SECURITY.md](SECURITY.md).

## Окружение

beam-bridge собирается только вместе с соседними репозиториями (через `replace`
в `go.mod`), поэтому клонируйте их в одну папку:

```bash
git clone https://github.com/AcelateOrg/beam-bridge
git clone https://github.com/AcelateOrg/xray-core-beam
git clone https://github.com/AcelateOrg/beam-tun
```

Нужен Go 1.26.

## Процесс

1. Форкните репозиторий и создайте ветку: `git checkout -b fix/коротко-о-сути`.
2. Делайте изменения небольшими и по одной теме.
3. Прогоните проверки: `make check` (build + vet + тесты), код отформатирован `gofmt`.
4. Ядро общее для десктопа и Android: если меняете API или поведение, проверьте,
   что `beam-desktop` собирается и тесты в нём проходят.
5. Откройте Pull Request: что изменилось и зачем, как проверяли.

## Правила кода

- Пути и сведения о среде приходят от оболочки явными параметрами, глобальных
  значений по умолчанию не добавляйте.
- К beam-core обращайтесь только через `core/coreapi` (это проверяет тест).
- Новая логика по возможности сопровождается тестами.

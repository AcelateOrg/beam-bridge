# Баннер профиля — гайдлайн

Баннер (`banner-image`, `branding.bannerImage`) — арт на фоне карточки профиля.
Шаблон для Figma: [`banner-template.svg`](banner-template.svg).

## Как Beam его рисует

- Картинка **вписывается по высоте** карточки и **прижимается к правому краю**.
  Сверху и снизу ничего не обрезается, масштаб не зависит от размера окна.
- Широкая карточка → слева просто больше цвета темы. Узкая → левая часть арта уходит за край.
- Левая половина фрейма плавно исчезает (маска 0% → 35% → 100% на x = 0 / 300 / 600),
  поверх — лёгкая подложка цвета карточки под текстом. Шва нет, рамки/виньетки не нужны.
- Карточка ~74 px высотой → фрейм 1200×200 показывается примерно 444×74 (×0.37),
  на 2×-экранах картинка остаётся чёткой.

## Фрейм

**1200 × 200 px** (6:1). Другой размер тоже сработает, но зоны ниже посчитаны под этот.

```
0            300            600                     1060    1200
┌─────────────────────────────────────────────────────────────────┐ 0
│            ·  скругления 24 px  ·                                │
│  FADE                     │  SAFE                  │  UI    │ 24
│  узор, градиент,        │  маскот, логотип,     │  фон   │
│  ничего важного        │  главный арт          │        │ 176
│            ·                                                   │
└─────────────────────────────────────────────────────────────────┘ 200
```

| Зона | Координаты | Что туда |
|---|---|---|
| FADE | x 0–600 | узор, линии, градиент. Уходит в прозрачность и лежит под текстом |
| **SAFE** | **x 600–1060, y 24–176** | главное: маскот, логотип, акцентный арт |
| UI | x 1060–1200 | поверх лежат кнопки («…», бейджи) — только фон |
| Края | y 0–24 и 176–200 | скругления углов, без мелких деталей |

## Чтобы было красиво

- **Фон заливай на весь фрейм**, без прозрачных краёв и рамок.
- **Тёмный, приглушённый арт** — поверх идёт белый текст. Яркое/белое только точечно в SAFE.
- **Без текста в арте.** Название и иконку Beam рисует сам (`profile-title`, `icon-url`).
- Крупные формы: на экране масштаб ×0.37, линии тоньше 3 px потеряются.

## Форматы

| Формат | Как отдать |
|---|---|
| **SVG** (лучше всего — чётко на любом экране) | https-URL с `Content-Type: image/svg+xml`, или inline `data:image/svg+xml;base64,...` до 96 KB |
| PNG / WebP / JPG | https-URL, экспорт @1x 1200×200, желательно до 300 KB |

Для SVG:
- в корне обязательно `viewBox="0 0 1200 200"` (и желательно `width="1200" height="200"`);
- в Figma: Export → SVG, галки *Outline text* и *Include "id"* можно снять;
- шрифты — только кривыми, внешние картинки/шрифты и скрипты внутри SVG не грузятся;
- сжать: `npx svgo banner.svg`.

## Как отдать в Beam

- заголовок подписки `banner-image: https://cdn.example.com/banner.svg`;
- или `"bannerImage"` в `Beam-Branding` / .beam / beam:// (см. [beam-links.md](beam-links.md)).

В заголовках используй https-URL: inline SVG в заголовке упрётся в лимиты nginx/панели (~8 KB).
